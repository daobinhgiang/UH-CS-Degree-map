# UH CS Degree Map

A web application to help University of Houston Computer Science students plan their degree path.

## Features

- Interactive degree map visualization
- Course prerequisites tracking
- Semester planning tools
- Progress tracking

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/daobinhgiang/UH-CS-Degree-map.git
cd UH-CS-Degree-map
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```
